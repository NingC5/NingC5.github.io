Web Log（网络日志），简称 Blog（博客）。

数据载体及选择

数据可以记录在笔记工具，或发布到平台社区。笔记工具适合个人整理、快速记录。平台社区虽然人员混杂且限制内容输出，但存在交流反馈和商业价值，是理想的内容“分发渠道”。

笔记工具，诸如 Notion、Wolai、语雀、Obsidian 和 Typora 等。

  • Notion：互联工作站
  • Wolai：Notion 的本土化版本，云笔记且支持本地存储
  • 语雀：云端知识库
  • Obsidian：本地知识库
  • Typora：原始的 MarkDown 编辑器
  • 语雀云端知识库：支持诸如定制 URL、在线编辑、自带评论功能等，还具备一定的社区环境。缺点是占用内存且卡顿、审核、付费等。「语雀停机事件」也引发用户对数据安全问题的广泛关注。快速拥有自己的博客，语雀或许是不错的选择 - 少数派 、为什么笔记用户要保卫自己的「数字主权」？ - 少数派

笔记工具不要随意切换，数据迁移比较繁琐。如果是本地编辑，个人推荐 Typora 或 Obsidian；如果偶尔需要网页编辑，可以使用语雀。

DeepSeek 锐评各大笔记软件：Obsidian、Notion、flomo、思源笔记、语雀、OneNote - 链滴

建立 Web 网站涉及域名、服务器、站点资源三要素。站点资源的主体即笔者的数据记录，笔者的需求是将 md 文档转换为 html 文件。幸运的是，此种转换器已经存在，且有一批集成该组件的博客框架将建站流程简化。

建站流程见下章。

静态博客框架，诸如 Jekyll、Hexo、Hugo 等，需要一定的配置和部署。动态博客框架，诸如 WordPress、Ghost、Typecho 等，适合追求一定自由度又不想从零搭建的人，功能需要付费。

个人博客的最终归宿是静态网站吗 - atpX

笔者选择静态博客框架，因为其自主性较高，且维护成本相对较低（比较动态）。笔者首先接触到 Hexo，它极易上手，且有很多功能丰富的主题。如果对博客构建速度有要求，可以选择 Hugo，其主题偏清新。

建站与规划

域名系统 - 维基百科，自由的百科全书

  • 域名 - 维基百科，自由的百科全书
  • 服务器 - 维基百科，自由的百科全书 、IP地址 - 维基百科，自由的百科全书

一般的建站流程如下：

  1. 注册域名（Domain Name）。域名注册商一般也提供域名解析服务。
  2. 获取服务器。有免费服务器，部分付费服务器送域名。
  3. 将站点资源部署到服务器上。此时，可以通过服务器的独立 IP 访问 Web 网站。
  4. DNS（Domain Name System，域名系统）解析域名——名称服务器（Name Server，简称 NS）添加 DNS 记录，绑定域名和服务器 IP。此时，可以通过域名访问部署在服务器上的网站。
  5. 注册数字证书，并部署到服务器的站点上 balabala ……

Github Pages

GitHub - 维基百科，自由的百科全书 、网页托管服务 - 维基百科，自由的百科全书

GitHub Pages 文档 - GitHub 文档

Github Pages 服务是很多静态博客框架白嫖的建站组件，它为静态站点提供免费的域名和服务器。

GitHub 是一个在线软件源代码托管服务平台，开源免费。GitHub Pages 是 GitHub 提供的一个静态网站托管服务，它直接从 GitHub Pages 仓库获取 HTML、CSS 和 JavaScript 静态资源文件。

  • GitHub Pages 仓库是指 name 固定的 GitHub 仓库——<username>.github.io 。
  • GitHub Pages 提供固定的子域名 <username>.github.io ，也支持自定义域名。用户通过 GitHub Pages 仓库设置的域名访问其静态资源文件。
  • GitHub Pages 服务器通过域名部分划分不同用户，用户共用其 IP。

GitHub Pages 网站受以下使用限制的约束：

  1. 每个账号只能创建一个 GitHub Pages 网站。
  2. GitHub Pages 源仓库的建议限制为 1 GB。
  3. 已发布的 GitHub Pages 网站不能大于 1 GB。
  4. GitHub Pages 站点的软带宽限制为每月 100 GB。“软带宽限制”指的是该网站每月允许的最大数据传输量限制，超过此限制可能会受到限制或额外收费。
  5. GitHub Pages 站点的软限制为每小时 10 次构建（可超）。如果您使用自定义 GitHub Actions 工作流程构建和发布站点，则此限制不适用。

“Hexo - Git - Github Pages 仓库（public）” 是一种常用的静态博客架构，简单、免费，但公开。先使用 Hexo 生成本地静态博客网站，再使用 Git 将本地静态站点 push 到 Github Pages 仓库。这样，一个网络静态博客网站就构建好了。你可以通过 https://<username>.github.io 访问该个人网络博客。

Blog 网站规划

网站建设除了围绕建站目的展开外，页面可访性、数据安全与隐私保护也是其绕不开的大山。

页面的内容和主题风格与建站目的紧密相连。

页面可访性关乎用户体感，简单且直观地说，即网站资源所在服务器到用户网络的数据传输（距离、速率、稳定性）。数据压缩、CDN 等资源优化手段都能提升页面可访性。

  • 压缩数据以减小数据量，减少浏览器渲染时间。
  • CDN（Content Delivery Network），内容分发网络，用于存储源站资源的副本，缩短资源到用户的距离。（简之，CDN 即节点服务器缓存数据，供用户就近获取。）

Blog 网站的数据安全及隐私保护处理比较简单。数据安全一般就数据丢失，做好数据备份即可。隐私保护方面，Blog 网站集成第三方服务时注意其数据收集与处理即可。以评论系统为例，Disqus 侵犯用户隐私，Valine 存在隐私泄露问题。

虽然都知道联网即裸奔，皇帝的新衣也不能抛弃不是。Disqus 因违反 GDPR 许可规则被罚款 250 万欧元

考虑到喜好、需求、精力和金钱，建站过程中一般会调整博客的主题风格、功能模块、写作流程，数据分布和网站防护等。

EXT：早期，很多站长考虑到个人博客网站在国内的可访性，使用 coding pages 而不是 Github Pages 来部署源站。后来，coding pages 项目终止，由此产生的数据丢失及其他问题致使不少博主终止博客，很多有价值的博文也随之消失。部分博文因 CSDN 的窃取而得以保留，后来者几乎只能从 CSDN 付费获取这些智慧结晶。

“Hexo - Git - Github Pages 仓库（public）”，该静态博客架构还有很大的改动空间。

  • 如果博客需要添加评论功能，可以将评论系统 Waline 部署到 Vercel。（GitHub Pages 只支持托管静态资源，而 Waline 涉及数据库交互。）
  • 简化与优化写作流程，减少精力消耗。
  • Github Pages 服务器位于国外，在国内的访问性较差，可付费购买国内服务器以部署 Blog 网站。GitHub Pages 源仓库存在容量限制，可以将博客中的图片、视频等资源存储到其他位置（阿里云 OSS 等），然后在博客中使用链接引用它们。

域名与 IP 地址

IP 地址（Internet Protocol Address）是分配给每台连接互联网的计算机或网络设备的唯一数字标识，通常以点分十进制（IPv4，例如 192.168.1.1）或冒号分隔的十六进制（IPv6，例如 2001:0db8::1）表示。主机之间通过 IP 地址来定位和通信。

域名（Domain Name，简称 Domain）是互联网中用来唯一标识网站或资源的字符地址，更便于人类记忆和使用。

域名通过 DNS 映射到对应的 IP 地址，用户通过域名访问网站，背后由 DNS 将其解析为实际的 IP 地址，完成与目标服务器的通信。

域名是一个由字母、数字和连字符组成的字符串，用点（.）分隔。域名从右到左依次是顶级域、二级域、子域（可选）。 以 www.google.com 为例 ，.com 是顶级域，google 是二级域，www 是子域。

顶级域（Top-Level Domain，简称 TLD）位于域名的最右端部分，用于划分互联网域名的类别或区域。顶级域主要分为以下几类：

  1. 通用顶级域（gTLD，generic TLD），适用于各种用途。例如：.com（商业），.org（组织），.net（网络相关），.info（信息），.biz（商务） 等。
  2. 国家和地区顶级域（ccTLD，country code TLD），代表特定国家或地区。例如：.cn（中国），.us（美国），.uk（英国），.jp（日本）等。
  3. 新通用顶级域（new gTLD），近年来新增的多样化域名，涵盖行业、兴趣、品牌等。例如：.app（应用），.tech（科技），.shop（商店），.中国（中文通用顶级域名）等。

二级域（Second-Level Domain）位于顶级域的左侧，通常是由企业、组织或个人注册的名字，用于标识具体的实体或网站。

我们付费注册的域名一般是 Apex Domain（顶级域名/根域名）。Apex Domain 是没有子域的二级域名本身，由【二级域 + 顶级域】组成。

TIP：Apex Domain 强调的是域名的最高层级，TLD 强调的是顶级域的类型。不要使用“一级域名”这种非正式用词来描述顶级域名。

子域（Subdomain）位于域名的左侧，通常在二级域名前面，用点（.）隔开。子域可以用来划分网站的不同部分或服务，例如：mail 用于邮件系统，shop 用于电子商务。子域名可以有多级，形成更复杂的层级结构。

TIP：Github Pages 的顶级域名是 github.io ，它分配给用户的固定子域名是 <username>.github.io 。

完整的域名由【子域（可选）+ 二级域 + 顶级域】组成。这三者结合起来，构成了完整的互联网域名体系，方便用户访问、组织和管理网站资源。
